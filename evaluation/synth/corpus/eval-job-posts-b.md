# 2026 春季招聘岗位汇编（技术类 B）

本文件收录华北区域技术岗位的公开需求，岗位编号同样以 J10 开头，注意与其他区域汇编中的编号区分。

## J101366 后端开发工程师

工作地点：北京。所属团队：交易中台。

岗位职责：负责交易系统核心链路的服务设计与开发，保障大促期间系统的稳定性。

任职要求：熟练掌握 Java 与 Spring Boot，熟悉 MySQL 分库分表，具备 5 年以上后端开发经验。能够主导核心模块的技术方案评审。

加分项：有高并发交易系统经验者优先；熟悉分布式事务者优先。

## J104521 前端开发工程师

工作地点：北京。所属团队：用户增长部。

岗位职责：负责活动页面与运营后台的前端开发，参与组件库建设。

任职要求：熟练掌握 TypeScript 与 React，熟悉 Vite 构建工具，具备 2 年以上前端开发经验。能够独立完成页面性能优化。

加分项：有可视化图表开发经验者优先。

## J102208 运维开发工程师

工作地点：天津。所属团队：基础架构部。

岗位职责：负责容器平台和发布流水线建设，参与线上故障的应急响应。

任职要求：熟悉 Kubernetes 与 Linux，掌握至少一种脚本语言，具备 3 年以上运维开发经验。能够独立编写发布与回滚方案。

加分项：有可观测性体系建设经验者优先。

## 招聘说明

本汇编岗位均要求全日制本科及以上学历，工作年限按毕业后正式工作经历计算。

华北区域岗位默认在北京、天津两地办公，异地候选人需在面试中说明到岗时间。

同一编号岗位只在一个城市开放，跨区域投递请以岗位编号为准。
