# 2026 春季招聘岗位汇编（技术类 A）

本文件收录华南与华东区域技术岗位的公开需求，岗位编号以 J10 开头。汇编内容仅包含岗位职责与任职要求，不包含薪酬信息。

## J106366 后端开发工程师

工作地点：深圳。所属团队：平台研发中心。

岗位职责：负责知识库服务与检索接口的开发和维护，参与线上问题排查与容量规划。

任职要求：熟练掌握 Python 与 Go，熟悉 PostgreSQL 与 Redis，具备 3 年以上后端开发经验。能够独立完成服务设计、接口实现和性能调优。

加分项：了解向量检索或 RAG 链路者优先；有高并发服务经验者优先。

## J108810 算法工程师（NLP）

工作地点：杭州。所属团队：智能应用实验室。

岗位职责：负责文本理解与生成模型的训练、评测和部署，参与检索增强生成方向的技术选型。

任职要求：熟悉 PyTorch，理解 Transformer 结构，具备硕士及以上学历，有 LLM 微调经验。能够独立设计离线评测方案并分析误差来源。

加分项：在检索增强生成方向有完整落地经验。

## J103045 测试工程师

工作地点：深圳。所属团队：质量保障部。

岗位职责：负责接口自动化测试和回归测试体系建设，维护持续集成流水线中的测试环节。

任职要求：熟悉 Pytest 与 Postman，能独立编写自动化用例，具备 2 年以上测试经验。了解接口契约测试和性能测试的基本方法。

加分项：有 RAG 或搜索类系统的测试经验。

## J107522 数据工程师

工作地点：广州。所属团队：数据平台部。

岗位职责：负责离线数仓建设和实时数据管道开发，支撑业务报表与指标口径治理。

任职要求：熟悉 SQL 与 Spark，掌握至少一种调度工具，具备 3 年以上数据开发经验。能够独立完成数据质量校验方案。

加分项：有湖仓一体架构实践经验者优先。

## 招聘说明

本汇编岗位均要求全日制本科及以上学历，工作年限按毕业后正式工作经历计算。

面试流程包含技术面、交叉面和 HR 面，技术面允许使用自己熟悉的编程语言作答。

候选人可在投递时注明期望城市，同一编号岗位只在一个城市开放。
